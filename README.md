# Statly

A guided statistics tutor and analysis tool for education researchers and students.
It teaches which test to run, checks the assumptions in plain language, runs the
analysis, and produces APA 7 tables and write-ups. All data stays on your computer.

## Features

- Import and clean up Qualtrics (and other survey) exports, with choice-text recoding,
  multi-select splitting, and stacking/linking across waves
- Guided Variable Interview to set roles, measurement levels, value labels, and scoring
- Test Advisor that asks a few questions and recommends the right statistical test
- A library of analyses with plain-language assumption checks and diagnostics
- Power analysis for planning sample sizes
- A Test Log that tracks every run, with multiple-comparison corrections
- Drag-and-drop chart builder covering common plot types
- APA 7 table, report, codebook, and data exports (DOCX/PDF/XLSX/CSV)
- Qualitative coding for open-ended responses, with a shareable codebook
- Study Planner that turns advisor answers into a full study write-up
- Learn library with tutorials on statistics concepts and how to use Statly
- Everything runs locally; your data never leaves your computer
