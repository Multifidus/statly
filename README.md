# Statly

A guided statistics tutor and analysis tool for education researchers and students.
It teaches which test to run, checks the assumptions in plain language, runs the
analysis, and produces APA 7 tables and write-ups. All data stays on your computer.

**This repository is not open source.** It is public temporarily; all rights are
reserved (see `LICENSE`). Third-party components keep their own permissive licenses
(`THIRD_PARTY_LICENSES.md`).
